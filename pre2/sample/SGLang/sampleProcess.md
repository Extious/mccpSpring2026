# SGLang poster process and requirement alignment

This document records how the SGLang poster package aligns with Presentation 2 requirements.

## 1. Deliverables in this folder

- `samplePoster.html`: poster draft in HTML.
- `outlineScript.md`: 2-3 minute oral script and Q&A notes.
- `sampleProcess.md`: requirement mapping and revision checklist.

## 2. Assessment requirements mapped to this version

| Requirement | Alignment in current files |
| --- | --- |
| Include topic, objective, methodology, findings, conclusion | Covered in poster sections from Introduction to Conclusion |

## 3. How this version improves submission readiness

1. **Rubric alignment**: each scoring area has explicit support in poster or script.
2. **Audience adaptation**: technical content is paired with plain-language framing.
3. **Presentation control**: script pacing targets about 2 minutes 20 seconds.
4. **Figures**: architecture (Fig. 1), RadixAttention (Fig. 3), throughput/latency (Fig. 5–6), ablation (Fig. 8) use `https://arxiv.org/html/2312.07104v2/xN.png` so the poster stays aligned with the paper.

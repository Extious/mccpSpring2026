SGLang: Efficient Execution of Structured Language Model Programs

Presenter: Zhan ZHAO

Layman summary AI systems often repeat the same long instructions many times. SGLang avoids this repeated work by reusing previous computation, which makes responses faster and reduces compute cost.

Introduction and Objective

Modern LLM applications include multi-turn chat, agents, and structured generation workflows. Many requests share long prompt prefixes, but existing systems recompute them repeatedly.

Objective: Build a serving system that reuses shared KV-cache states across calls to improve throughput and reduce latency without changing model architecture.

Methodology

  • Frontend DSL: Programmatic primitives for structured generation workflows.
  • RadixAttention: KV cache organized in a radix tree to detect and reuse shared token prefixes.
  • Cache-aware scheduler: Prioritizes requests with high cache overlap to maximize reuse.

Key Findings

Experiments across multiple workloads show that SGLang improves both speed and serving efficiency against strong baselines.

Main result: up to 6.4x higher throughput and up to 3.7x lower latency.

Ablation Evidence

Ablation studies remove key components one by one, including radix-tree reuse and cache-aware scheduling. Performance drops in each variant, supporting the causal contribution of each design choice.

Conclusion and Impact

SGLang reframes LLM serving as a cache-reuse problem and provides a practical system-level solution. The approach improves user latency and lowers infrastructure cost, which is important for production AI services.
